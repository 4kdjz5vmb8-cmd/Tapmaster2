ACCESSIBILITY TOOLKIT

iOS includes built-in tools that can help with touch interactions. Setup and available features depend on your iOS version.

☝ AssistiveTouch

On-screen menu for supported gestures and custom actions.

Settings → Accessibility → Touch → AssistiveTouch

⇄ Switch Control

Accessibility control using switches, scanning, and supported recipes.

Settings → Accessibility → Switch Control

✋ Touch Accommodations

Adjust how the screen responds to touches and gestures.

Settings → Accessibility → Touch → Touch Accommodations

WHAT TAPMASTER CAN DO

This web app cannot toggle system settings or inject touches into other apps. Built-in accessibility tools have their own capabilities and limitations.
